# Security policy

CheckCG is a static site: weights, aircraft and shared links are processed in
the browser and never stored on a server.

## Reporting a vulnerability

Please report security issues privately through
[GitHub security advisories](https://github.com/PabloAlaniz/wb-aviation/security/advisories/new)
instead of a public issue. Include the steps to reproduce and the affected URL
or file. You should get an answer within a week.

Errors in aircraft data (weights, arms, envelope limits) are safety issues but
not vulnerabilities: report them with the
[bug template](https://github.com/PabloAlaniz/wb-aviation/issues/new?template=bug.yml).

## Supported versions

Only the version deployed at [checkcg.com](https://checkcg.com) (the `main`
branch) is supported.
